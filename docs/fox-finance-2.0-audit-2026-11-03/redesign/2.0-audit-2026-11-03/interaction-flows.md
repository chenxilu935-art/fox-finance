# Fox Finance 2.0 核心交互流程

提案，2026-11-03。所有“保存成功”以权威数据源提交确认返回为准；状态流：编辑草稿 → 校验 → 保存中 → 已保存 / 待处理冲突 / 失败保留草稿。网络中断不自动改写 Markdown；不预先承诺服务端尚不具备的撤销、批量原子性或冲突版本控制。

## 新增交易

全局“记一笔”（可绑定 Obsidian 快捷键）→ 金额获得焦点 → 默认支出、今天、最近有效账户，分类显示近期常用候选 → 保存。金额以十进制字符串校验；允许零仅限业务明确支持的余额对账，不允许解析“12abc”为12。日期和账户一直可见为芯片，可直接更改；首次使用无账户时引导创建，不悄悄创建“现金”。未知分类明确显示“待分类”，不得显示“餐饮”却提交空值。

收入/支出/转账是主类型；退款从原消费详情创建并关联，投资相关在高级动作中保留。转账需来源、去向、金额，两账户不可相同；跨币转账显示两边金额及汇率，源不支持时明确禁用。更多展开备注、标签、子分类、特殊类型。显示默认值来源为“上次使用”，清除/调整后持续生效，不无限推测。

保存中锁定按钮并使用幂等键；成功提示记录摘要及“再记一笔”，继续记账只保留账户/类型/分类，清空金额/备注并重新核对日期；失败保留所有输入并提供重试。草稿只在明确需要时本地保存，不默认新增第二账本。

自然语言可选输入“昨天午饭28 微信”：本地规则解析 → 金额/日期/账户/分类预览，缺项高亮 → 用户确认保存。先做结构化输入及最近值，再评估 Ollama。AI 结果不得直接执行写入；模型不可用时正常记账不受影响。

## 修改、删除与批量

交易页筛选/搜索 → 选择记录 → 单层详情抽屉 → 编辑（所有字段原样预填）→ 差异摘要 → 条件写入。日期跨月保存由权威层一次完成，镜像跟随新月份；不能用旧列表行号修改。版本冲突显示本地草稿/服务器最新差异，允许重新应用字段，不静默覆盖。

删除：显示日期、金额、账户及关联退款/转账影响 → 确认 → 权威删除标记/恢复机制 → 更新统计及镜像。若服务支持可恢复删除，提供真实“撤销”；否则提示恢复路径，不能只做视觉撤销。撤销恢复失败须明确显示。删除不因 Markdown 缺行触发。

批选默认仅选当前明确范围，显示选中数量及总影响。先支持批量改分类/标签与审核，不把批量删除作为默认主操作。验证失败逐项反馈；若接口无原子批量则在确认前标明可能部分完成，重试只提交失败项，避免重复。

## 账户与分类

账户页 → 添加（名称、类型、币种、期初余额及日期）→ 校验 → 权威创建。详情展示当前余额、账面流入流出、流水和对账；历史月份显示期末余额，不能复用当前值。对账：输入实际余额 → 计算差额 → 说明会产生调整记录 → 确认保存。负债/负余额按模型能力处理，禁止悄悄截为0。

改名保留稳定 ID；有历史引用账户提供归档，不直接删除。分类同样按 ID，合并先展示交易数与预算引用，确认后才提交，不能通过改字符串批量破坏历史。

## 预算

预算页 → 月/年范围 → 分类与金额 → 显示包含子分类/退款抵减/账户范围规则 → 保存。已存在预算先预填，防同范围重复。卡片显示“预算/已用/剩余或超额/范围”，进度条超过100%保留超额数值。未设置不显示已用0%；零预算不进行除法。点击分类下钻保持相同统计口径的交易。

## 账单导入与 Markdown 差异

选择文件（只读预览）→ 编码/列映射/日期币种确认 → 生成候选记录 → 确定重复/可能重复/错误分类 → 用户分批审核 → 显示将新增、修改、跳过数量 → 权威提交 → 结果收据与失败重试。完全相同的真实交易不一律删除；保留来源行与导入批次用于追踪。

Markdown 手改：镜像基准/文件当前内容/权威记录三方比较 → 按字段显示新增、修改和疑似删除 → 选择接受为变更候选或恢复镜像 → 校验与冲突处理 → 权威确认后重新生成。文件缺失、行消失、格式损坏一律不自动删除权威记录。备注中的竖线/换行必须安全转义。手写复盘放独立区域，生成时保留。

## 财富分析与月度复盘

年轮分析 → 日期范围 → 资产变化/净支出结构/预算偏差 → 查看指标定义与同期比较 → 点图表进入同范围流水。退款抵减消费、内部转账不算支出、投资现金流与收益分别显示；缺汇率时分币种呈现，不虚构总额。

月度复盘 → 检查数据截至时间与待审核数量 → 本月三项变化、异常交易和预算偏差 → 用户写感受/下月一个行动 → 预览年轮笔记 → 生成独立镜像区块，保留手写内容。未完成同步时允许生成“截至某时”的草稿，不标为最终结账。重复生成先差异预览，不覆盖人工记录。

## 通用反馈与可访问性验收

空、加载、部分成功、失败、离线、连接过期、同步冲突、镜像待更新均有文字说明和恢复动作。键盘 Tab 顺序可预期；Esc 关闭前检查未保存草稿；关闭后焦点返回入口；弹窗焦点受控。筛选无匹配与尚无记录分开显示。所有高频按钮有中文标签，颜色不是唯一状态信号。目标：有效默认值下普通支出只输入金额即可保存；该目标须通过模拟数据可用性验证，当前未实测。

## 同步冲突边界

以上版本冲突界面仅适用于新增 Fox API 能检测的条件写入冲突。Z 原生 Android 同步目前是整行 HLC LWW，不提供冲突历史；满足 A07 必须补同步历史/冲突机制。用户未另行批准降低验收标准前，不能以接受 LWW 代替此关口。
