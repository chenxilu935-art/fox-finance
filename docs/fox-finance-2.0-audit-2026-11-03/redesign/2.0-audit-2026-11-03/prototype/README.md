# 独立交互原型

用桌面浏览器打开 index.html，无需构建、依赖安装或服务。所有数据虚构且仅在内存，刷新恢复；没有外部请求、存储、API或真实账本访问。

可交互：四场景导航、金额优先录入、编辑、单笔/批量删除、最近一次撤销、搜索与类型筛选、更新演示预算、断连阻止财务写入、复盘预览。桌面快捷键 N 开始记账，Esc关闭弹窗。完整设计为五导航，账户/分类/导入和特殊交易未在原型实现。

静态示意：净资产、收入、提醒和趋势图，不随CRUD更新。隐私开关仅局部模糊示意，未隐藏所有金额/辅助文本，不应拿来保护真实隐私。预算分类额度为独立示例，不随总预算自动分配。

2026-11-03使用现有Playwright与系统Edge无头验证：新增/编辑/删除/撤销/搜索/断连拒绝新增与预算写入/预算更新通过；1440桌面与390窄窗截图审查，390页面无横向溢出，无pageerror。未覆盖全部键盘/读屏、生产Obsidian或Android。
