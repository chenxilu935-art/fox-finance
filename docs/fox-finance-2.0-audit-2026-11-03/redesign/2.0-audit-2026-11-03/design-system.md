# Fox Finance 2.0 设计系统提案

2026-11-03，待批准。定位“森林里的私人财富观测站”：安静、可读、长期陪伴。森林视觉保留在品牌封面、树木年轮纹理、插画与关键空状态；数字、表格、表单使用稳定底色。避免每张卡都发光或所有界面都铺复杂背景。复用已有本地图片，不加载外部字体/CDN，不新增依赖。

## 颜色与主题 token

以下为拟定色值，非已通过的对比度测试。上线验收须测普通文字4.5:1、大字与组件边界3:1，并检查真实图片叠层和选中/禁用状态。

| 角色 | 银河森林·深色 | 森林玻璃屋·浅色 | 使用 |
|---|---|---|---|
| canvas | #101F1A | #F5F1E7 | 页面底色 |
| surface | #1A2D25 | #FFFDF7 | 表格、表单实色衬底 |
| elevated | #233B30 | #ECE7D9 | 抽屉与悬浮 |
| text-primary | #F1F0E6 | #20392D | 重要数字、正文 |
| text-secondary | #B6C6BB | #546B5B | 辅助信息 |
| border | #526B5D | #B4BEB0 | 可辨认控件边界 |
| action | #DAB879 | #65501F | 主按钮、提灯色 |
| positive | #92D6AE | #21633F | 流入/正变动（配+符号） |
| negative | #FFB3A4 | #9E382C | 流出/负变动（配−符号） |
| warning | #F0C26A | #795200 | 待处理/超额（配文字） |
| info | #A8CBE4 | #285977 | 同步、基期说明 |

原来的紫色星光可作为夜空装饰小面积保留，不承担全部操作与数据语义。正负颜色固定，投资、转账使用中性标签，转账不使用纯消费红色。图表固定类别色及文字图例，色盲可读、黑白导出仍可辨。token 作用域仅 Fox 容器/弹窗；不在 :root 覆盖 Obsidian 或其他插件。

## 字体与数字

标题使用本机有则采用的宋体系列（Noto Serif CJK SC / Source Han Serif SC / Songti SC / SimSun），传达年轮书写感；正文使用本机清晰中文字体（Microsoft YaHei / PingFang SC）。无字体下载依赖，跨系统回退是已知差异。金额启用 tabular-nums 与等宽数字，币种符号不代替 ISO 货币提示。

| 层级 | 字号/行高 | 用途 |
|---|---|---|
| Display | 36/44，紧凑28/36 | 单个净资产主数字 |
| H1 | 26/36 | 页面标题 |
| H2 | 20/28 | 区域标题 |
| Body | 14/22（可跟随 Obsidian 缩放） | 说明和交易 |
| Label | 13/20 | 字段与表格头 |
| Caption | 12/18 | 更新时间、来源 |

避免10px浅色关键信息；长账户名称可换行，金额保留完整，备注省略需可查看全文。中文金额输入不自动吞零或修改精度。

## 间距、密度与结构

基础4px：4、8、12、16、24、32、48。页面内边距24（紧凑16），区域间距32；卡内20–24，字段间16，标签到输入8。大部分工作卡圆角12、表单8、抽屉16。最多两级表面，阴影只提示空间层次；玻璃效果不承担文字可读性的唯一保障。

交易行舒适密度48px，紧凑40px；主按钮/触屏目标至少44px，桌面次级控件至少36px。金额右对齐，文本左对齐；日期与货币列稳定。列表表头、过滤摘要、选择状态可见，不在hover时才提供操作。

## 组件规范

- 卡片：标题、金额、范围/更新时间、下钻动作。可点击卡明确焦点与按钮语义；纯展示卡不伪装可点。
- 弹窗：确认类不超过480px；快记常规520px；复杂编辑使用侧抽屉，避免层叠弹窗。窄窗转全屏。标题、内容、固定动作区，Esc 和未保存提醒一致。
- 按钮：主动作每个任务区一个；次级为边框、普通为文字，危险动作独立且中文命名。主按钮忙碌态锁定并显示“保存中”；禁用说明可访问。
- 输入：永久 label，placeholder 只给例子；金额首焦点，错误贴字段，保留原文；日期/账户/分类为可展开芯片，默认值明确可见。
- 图标：已有星空狼、幼苗、财富树、提灯作为24–32px品牌图标；功能按钮用单一线性图标体系并带文本。不要将星星同时用作隐私、收藏和彩蛋。
- 表格：语义 table 或等价可访问结构；可排序列有状态；编辑/更多在键盘 focus-within、触屏时可见。批选显示范围，跨页选择必须明确。
- 图表：标题写问题（“本月钱花在哪里”）；副标题范围与口径；图例、文本摘要、数据表可访问。饼图类别多时用排序条形图+其他；趋势用折线或柱图并标零/缺数据。交互下钻保持筛选。
- 预算：预算、净支出、剩余/超额和时间节奏四值，进度条可视觉截顶但超额文字保留；不把超支道德化。
- 通知：保存成功以权威确认触发；局部错误就地重试；严重错误常驻。动态状态用 aria-live，不能只靠短暂 toast。

## 全状态定义

| 状态 | 可观察表达 | 行为 |
|---|---|---|
| 初始加载 | 骨架+正在读取本地数据 | 不将0显示成真实余额 |
| 无数据 | 原因+创建/导入入口 | 区分未连接与真空账本 |
| 筛选无结果 | 当前筛选+清空筛选 | 保留日期范围 |
| 保存中 | 明确动作+禁止重复提交 | 可继续阅读，保留草稿 |
| 成功 | 记录摘要与继续动作 | 余额/列表/镜像状态分别更新 |
| 服务离线 | 最后成功时间、仅缓存标记 | 不伪装可写；保留草稿 |
| 版本冲突 | 最新与草稿字段差异 | 用户选择后重新校验 |
| 部分失败 | 成功数/失败项/重试 | 重试不重复成功记录 |
| 镜像过期 | 权威已保存、镜像待更新 | 单独重试导出 |
| 隐私模式 | 金额替换为遮蔽字符 | 图表tooltip/列表/辅助文本同步遮蔽 |

动效80–180ms用于反馈，220ms以下用于抽屉；遵守 prefers-reduced-motion，不做粒子或自动循环背景。主题切换不影响会计语义与页面位置。隐私模式是防旁观功能，不替代数据库安全；不得宣传CSS模糊为加密。

## 后续验收清单

320/480/768/1280px容器、200%缩放；全键盘新增编辑删除与焦点返回；长中文账户/备注、多币种小数、超大负数；深浅色及图片关闭；强制色彩/减少动画；Canvas文本等价；离线/迟返回/重复保存。设计文件和原型仅示范，均不等于这些测试通过。
