# 安全与隐私审查

2026-11-03；静态源码审查，非渗透测试、安全认证或原生Android实测。没有读取真实ZCashflow数据库、财务明细或令牌。源码基线见 integration-architecture.md；本阶段没有改安全配置。

## 结论

loopback API可以合理限制暴露面，但“仅本机”不意味着免认证。桌面应用/Obsidian第三方插件拥有当前用户权限时，不能靠HTTP令牌防止同用户恶意软件读取全部可见内容。目标是防局域网访问、网页跨站误调用、凭据误同步、误写及故障数据损坏；当前用户系统已被控制不在应用可单独解决的保证内。

推荐上线前高优先级门槛：认证和Host校验、禁止直连数据库、原子版本条件和幂等、加密模式落盘确认、可恢复历史备份、受控Markdown明文暴露、原生同步冲突可见性。

## 本机API威胁与控制

1. **同Wi-Fi其他设备探测**：新接口只绑127.0.0.1，非0.0.0.0；测试物理LAN IP连不上业务API。原生同步端口仍按配对规则开放。防火墙不能代替正确bind。
2. **恶意网页/DNS rebinding**：Host严格匹配数字loopback及端口；Bearer所有路由必需；无Cookie、无GET写入；JSON与Origin精确限制；不允许任意自定义反向代理。跨站读取被CORS拒绝不等于跨站写安全。
3. **令牌外泄**：256bit随机、配对显示一次、支持撤销轮换；操作系统凭据保护；禁止入Git/data.json/镜像/导出/错误栈；应用退出可撤销会话。配对失效显示明确重连，禁止降级无认证。
4. **混淆代理/越权调用**：服务端路由业务白名单，只给Fox已批准实体能力；不暴露原始SQL、文件读写、reset、导出任意路径、vault_enable/disable/forget、LAN私钥。
5. **注入和数据污染**：金额/日期/币种/账户/分类引用服务端验证；参数化SQL；Markdown表格竖线/换行/YAML特殊字符转义；用户笔记渲染用纯文本或安全DOM，禁innerHTML拼接交易内容。原始文件名不决定镜像输出路径。
6. **资源耗尽**：正文/批量/分页上限；超时/限流/并发；拒绝无限嵌套JSON和无边界附件。对原生LAN线程/附件内存边界做单独压力审计，不能以API限流覆盖原生协议。
7. **并发覆盖**：API原子OCC+幂等+墓碑；原生同步另建冲突/历史策略。不存在“有UUID所以不会重复或丢更新”的保证。
8. **磁盘满/断电**：提交、flush、响应边界故障注入；原子镜像临时文件+替换；写失败不反复重发业务命令；操作结果可查询。加密快照原子替换仍需测试Windows断电/磁盘错误恢复。

## 财务隐私与Markdown镜像

Markdown是**明文降级副本**，即使ZCashflow vault已加密，Obsidian Vault、备份、Windows搜索、插件和Git仍可能接触镜像。不应把“本地”当“加密”。默认不导出附件/OCR文本、令牌、同步身份、完整调试响应；镜像包含哪些金额/账户名须用户确认，支持汇总视图和金额隐藏。UI隐藏仅防旁观，不等于文件加密。

建议专属Finance/Mirror目录与显式生成标记，非旧Ledger就地覆盖。首次输出前若目标存在手改或未知文件，停止该文件生成并进入差异核对。镜像外不扫描无关笔记，不以全Vault索引支持账务对比。用户自由批注区与机器区分离，hash仅覆盖明确生成区；删除镜像文件不等同删除权威交易。

安全日志只留时间、requestId、错误码、资源类别和必要匿名ID，不记金额/商户/备注/账号/正文hash可关联个人资料的完整清单。账本迁移映射和哈希清单本身也是敏感数据，保存D盘受当前用户ACL保护的非公共目录，不默认上传GitHub。公开审计文档只含虚构例子、结构和代码路径。

## 备份与恢复

后续经批准使用应用一致快照/SQLite backup方式，避免运行中仅复制.db漏WAL；vault备份应从应用加密快照生成并包含所需附件、元数据和版本。恢复演练在独立D盘目录、禁LAN连接环境运行，使用独立ledgerEpoch并重新配对，防旧设备重新覆盖恢复账本。备份密码恢复方案先确认；本阶段没有备份/迁移/恢复真实数据。

切换后要回滚，必须先停所有写入口，保存新系统切换后的增量，然后恢复旧环境并对增量逐笔核对。仅把旧Markdown还原会丢失新交易，不能叫完整回滚。

## 验收与未验证范围

- 远端LAN对业务端口不可达；未授权读取/写入全部拒绝。
- 网页Origin/Host变体、GET副作用、超大请求、已撤销令牌均测试。
- Android离线同一交易的修改/删除冲突可见；若采用原生LWW，需用户明确接受且可恢复历史验证，不能满足“冲突可见”就静默放行。
- 应用锁定/退出后API拒绝服务；前端自动锁是否实际卸载Db需另审，不从遮罩UI推断内存数据不可用。
- 磁盘满/崩溃、幂等重启、备份恢复、日志凭据扫描、镜像注入案例均需虚构数据完成。
- 本阶段未运行构建、安装APK、真实配对、端口探测或密码学测试；没有发现本机ZCashflow运行版本可供验证。
